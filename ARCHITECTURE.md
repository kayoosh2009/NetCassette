# NetCassette 📼
> Децентрализованный P2P-аудиоплеер в ретро-стиле кассетника для Linux (KDE Plasma).

---

## 📂 Структура проекта

```text
NetCassette/
├── Cargo.toml               # Конфигурация сборки и зависимости (Tokio, Slint, librqbit, Rodio, zbus)
├── build.rs                 # Скрипт сборки Slint-интерфейса
├── icons/                   # Графика и векторные иконки интерфейса
│   ├── play.png             # Кнопка воспроизведения
│   ├── stop.png             # Кнопка остановки
│   ├── prev.png             # Предыдущий трек
│   ├── next.png             # Следующий трек
│   ├── menu.png             # Открытие основного окна библиотеки
│   ├── home.png             # Сайдбар: Главная страница
│   ├── network.png          # Сайдбар: P2P Торрент-сеть
│   ├── folder.png           # Сайдбар: Открытие системной папки с музыкой
│   └── info.png             # Сайдбар: Информация о программе
├── src/
│   ├── main.rs              # Точка входа: логика окон, D-Bus MPRIS, события и координация
│   └── torrent.rs           # P2P-движок: BitTorrent-сессия, DHT, раздача и скачивание

    ├── appwindow.slint      # Плавающий виджет-кассета у края экрана (KDE Dock)
    └── playlist.slint       # Большое окно плеера и библиотеки (центр экрана)
```

## 🔍 Назначение и обязанности каждого файла

### 1. `Cargo.toml`
Манифест проекта на Rust:
* **UI:** `slint` (нативный декларативный UI).
* **Async Backend:** `tokio` (полный набор многопоточных утилит).
* **P2P:** `librqbit` (современный BitTorrent v1/v2 движок на чистом Rust с Mainline DHT).
* **Audio:** `rodio` (воспроизведение MP3/FLAC/OGG через ALSA/PulseAudio/PipeWire).
* **Linux Integration:** `zbus` (MPRIS D-Bus мост), `directories` (пути XDG), `notify-rust` (уведомления).

---

### 2. `src/main.rs`
Сердце приложения, связывающее UI, систему и фоновые сервисы:
* **KDE / KWin Docking:** настраивает кассету через `xprop` и правила KWin как системный док (без иконки в таскбаре, всегда поверх окон, авто-прятание через 7 секунд бездействия).
* **Менеджмент окон:** управляет связкой «Виджет-кассета ↔ Окно библиотеки `PlaylistWindow`». Центрирует окно библиотеки при открытии.
* **Слушатель MPRIS:** непрерывно синхронизирует метаданные трека (название, артист, статус, обложка) с внешними плеерами системы через D-Bus и транслирует в оба окна.
* **Инициализация P2P:** при старте запускает `TorrentEngine`, привязывая рабочую папку к `~/Music/NetCassette/`.
* **Файловый менеджер:** перенаправляет клик по кнопке «Папка» в нативный Dolphin/xdg-open.

---

### 3. `src/torrent.rs`
Изолированный асинхронный модуль для работы с P2P-роем:
* **Сессия:** поднимает `librqbit::Session` с активированным DHT для поиска пиров без трекеров.
* **Прием magnet-ссылок:** метод `add_magnet` парсит ссылку, ищет метаданные и запускает загрузку трека.
* **Сидирование:** скачанные файлы автоматически остаются на раздаче, формируя децентрализованную сеть.
* **Сбор метрик:** метод `list_swarms` отдает наружу текущий прогресс, объем данных, статус завершения и хэш раздачи.

---

### 4. `ui/appwindow.slint`
Компактный плавающий виджет-кассета:
* **Геометрия:** поддержка изменения размера за угол, вертикальное перетаскивание с сохранением позиции в `config.json`.
* **Анимации:** выезжающая панель, индикатор активности, авто-скрытие к правому краю монитора.
* **Элементы:** кассетный визор с градиентом и обложкой, кнопки управления воспроизведением и кнопка вызова большого окна.

---

### 5. `ui/playlist.slint`
Полноценное окно музыкального центра:
* **Палитра:** выдержана в темно-графитовых кассетных тонах (`#262626`, `#1c1c1c`, `#383838`).
* **Боковая панель навигации:** табы переключения экранов (*Главная*, *Сеть*, *Инфо*) и системное действие *Папка*.
* **Нижняя полоса проигрывателя:** квадратный винил-бокс **1:1** под обложку, метаданные и мини-кнопки управления.
* **Крестик:** нативное закрытие/скрытие окна в правый верхний угол.
